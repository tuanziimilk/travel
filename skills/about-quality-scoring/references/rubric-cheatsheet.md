# About 质检评分速查表（A/B/C/D）

本表仅用于快速判断信号；正式输出必须严格按 `SKILL.md` 的 A/B/C/D 与扣分规则执行，不得新增维度。

## A（3.0）基础规范与硬性质量

**【硬规则 1】必须且只能用 `{Mer.}` 指代商家（输出里也只能出现 `{Mer.}`）。**  
**【硬规则 2】不得出现第一人称（I/we/our/我/我们/咱们等）。**

**高分信号**
- 全文用 `{Mer.}` 统一指代商家，不出现 TermName/域名当商家名
- 语言与 `Country` 对应的语系/语言环境匹配（参考 `country-language-map.json`；值为语系代码，如 `en/de/fr/zh-tw`）
- 无模板残留、无乱码、无明显语法/拼写问题
- 字数适中，信息密度高，少废话

**低分信号**
- 未使用 `{Mer.}`，或出现真实商家名/TermName/Domain 作为商家名
- 出现第一人称或“站在商家口吻”的叙述
- 复制粘贴痕迹：重复段落、占位符、奇怪符号、混杂语言
- 过短导致信息不足；过长导致冗余堆叠

**字数阈值建议（可配置）**
- 理想区间：约 120–220 词/字（按语言而定）
- 明显偏短：< 120（容易缺主营/范围/信息点）
- 明显偏长：> 260（容易冗余、重复、AI 腔）

## B（4.0）业务描述清晰度与信息完整
**高分信号**
- 读完能清楚回答：`{Mer.}` 是什么、主要提供什么（主营/服务/品类）
- 有“范围与边界”：覆盖的商品/服务类别、优惠形式（如优惠券/折扣/促销码等）说明清楚
- 结构清晰：2–4 句话/段落递进，先定义再补充细节

**低分信号**
- 只写“提供最佳体验/一站式/致力于”等口号，缺少具体主营
- 过度泛化：什么都做、面向所有人、没有品类/场景
- 前后不自洽：一会儿写优惠券，一会儿写物流/退换等但未在原文出现

## C（2.0）SEO 语义与关键词自然覆盖
**高分信号**
- 关键业务词自然出现（与原文一致）：如“优惠券/折扣/促销码/优惠信息”及相关品类/场景词
- `{Mer.}` 出现自然，不生硬、不频繁重复
- 关键词分布均匀，不堆叠同义词列表

**低分信号**
- 完全不提核心关键词，读者无法判断是否与优惠券/折扣相关
- `{Mer.}` 强行插入导致语法不通顺
- 关键词堆砌：coupon/discount/promo code 等重复轰炸，信息不增量

## D（1.0）可读性与“非 AI 腔”（含本土化）
**高分信号**
- 句子简洁自然，少套话；每句都有信息增量
- 用当地常见表达方式（与 `Country` 语言环境一致），避免直译腔
- 不“销售话术化”，更像中立介绍

**低分信号**
- AI 模板腔：反复出现“致力于/最佳/我们相信/为您提供”
- 读起来生硬：长句堆叠、被动语态过多、连接词滥用
- 本土化差：用词不符合当地习惯、明显机翻感
