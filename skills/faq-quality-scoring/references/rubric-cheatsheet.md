# FAQ（优惠信息场景）评分速查表（A/B/C/D）
本表用于快速判断信号；正式输出必须严格遵守 `SKILL.md`。

## A（0-3）结构完整与FAQ可读性
**高分信号**
- 问题明确且可检索，答案直接可用。
- 覆盖核心优惠主题：折扣类型、适用对象、使用条件、时效限制、售后关联。
- 条理清晰，用户可快速定位“我能否用、怎么用、什么时候失效”。

**低分信号**
- FAQ 仅有泛泛描述，没有可执行信息。
- 缺失关键主题（如叠加规则、有效期、排除项）。
- 问题与答案不匹配，或答案重复空话。

## B（0-4）政策准确与可执行性
**高分信号**
- 描述清楚边界条件：门槛、排除品类、是否可叠加、适用地区。
- 说明常见异常：优惠码无效原因、生效时点、退款后的处理逻辑。
- 不夸张承诺，不编造细节。

**低分信号**
- “可能/通常/一般”这类模糊话术太多。
- 前后矛盾（例如一处说可叠加，另一处说不可叠加）。
- 缺少时效或适用条件，容易误导用户。

## C（0-2）本地化与表达
**高分信号**
- 语言和 Country 匹配，表达自然。
- 币种/日期/配送相关术语本地化正确。
- 句子简洁，阅读负担低。

**低分信号**
- 语言与国家不匹配，明显机翻腔。
- 术语混乱（折扣码、优惠券、礼品卡等概念混用）。

## D（0-1）SEO与可发现性
**高分信号**
- 问句接近真实搜索意图：
  - student discount
  - first order discount
  - promo code not working
  - can I stack coupons
- 关键词自然出现，不堆砌。

**低分信号**
- 关键词缺失，无法被搜索命中。
- 同义词重复堆积，读感生硬。
