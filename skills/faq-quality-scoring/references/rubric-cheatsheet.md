# FAQ（优惠信息场景）评分速查表（A/B/C/D）
本表用于快速判断信号；正式输出必须严格遵守 `SKILL.md`（含扣分档位、发布阈值、并列规则）。

## A（0-3）结构完整与 FAQ 可读性
**高分信号**
- 问题可检索、答案直给，用户能快速判断“能不能用、怎么用”。
- 覆盖核心主题：折扣类型、适用对象、条件门槛、时效限制、售后关联。
- 组织清晰，无重复与答非所问。

**低分信号（常见扣分）**
- 问答不匹配、绕弯：`-0.4 / -0.8 / -1.2`
- 核心主题缺失（仅对资格/范围/限制类、异常排查类执行；每缺 1 类）：`-0.3`（最多 `-1.5`）
- 信息组织混乱：`-0.2 / -0.5 / -0.8`

## B（0-4）政策准确与可执行性（核心维度）
**高分信号**
- 条件清楚：门槛、排除项、叠加规则、适用范围、生效时点。
- 有可执行步骤：用户知道下一步该做什么。
- 不夸大、不冲突、低投诉风险。

**低分信号（常见扣分）**
- 关键条件缺失：仅对资格/范围/限制类、异常排查类强制执行；每缺 1 类 `-0.5`（最多 `-2.0`）
- 纯操作步骤类 FAQ 不因“未覆盖全部范围字段”直接扣分（避免误伤）
- 模糊话术（通常/可能）无边界：`-0.4 / -0.8 / -1.2`
- 前后冲突或误导风险：`-0.8 / -1.2 / -1.8`
- 无执行步骤：`-0.4 / -0.8 / -1.2`

## C（0-2）本地化与表达
**高分信号**
- 语言与 Country 匹配，表达自然，术语地道。
- 货币/日期/配送等表述符合本地习惯。

**低分信号（常见扣分）**
- 语言不匹配：`-0.6 / -1.0`
- 术语与表达不自然：`-0.2 / -0.5 / -0.8`
- 模板腔/翻译腔：`-0.2 / -0.4 / -0.6`

## D（0-1）SEO 与可发现性
**高分信号**
- 问句贴近真实搜索意图：
  - student discount
  - promo code not working
  - can I stack coupons
  - first order discount
- 关键词自然，不堆砌。

**低分信号（常见扣分）**
- 问句不贴搜索场景：`-0.2 / -0.5`
- 关键词缺失或堆砌：`-0.2 / -0.5`
- 满分约束：存在任一 SEO 负向信号时，`D` 不得为 `1.0`（上限 `0.8`）

## 发布阈值（必须同时满足）
- `score_total >= 8.0`
- `A >= 2.0`
- `B >= 3.0`
- 未命中高风险红线

## 高风险封顶（必须同时满足）
- 命中高风险红线：`pass_for_publish=false`
- 命中高风险红线：`B <= 3.4`
- 命中高风险红线：`score_total <= 7.9`

## 高风险红线（在 notes 明确标注）
- 叠加规则冲突
- 生效时点缺失
- 适用范围/排除项缺失（仅对资格/范围/限制类 FAQ 触发；纯操作步骤类不强制）
- 退款处理缺失
- 绝对化承诺无条件边界
